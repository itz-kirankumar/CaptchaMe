Agent lane

An honest AI agent should not have to fake being a person. It declares itself with a signed key (the shape of the Web Bot Auth standard), skips the human checks, and gets its own fair-share budget.

Demo agent, in your browser

This generates a fresh Ed25519 key, signs the server nonce, declares itself, then calls the protected API until its budget runs out.

For your own agent

POST /api/agent/nonce, sign the nonce with your Ed25519 key, POST /api/agent/declare with {pubkey, signature, nonce, operator}. Use the returned token as a Bearer token on the protected API. OpenClaw, LangGraph, a cron script: anything with a key can use the lane.
