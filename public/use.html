Protect your site in three lines

1. Paste the widget

<script src="https://captchame.vercel.app/widget.js"
        data-site="demo-site"></script>

2. Verify the pass server-side

const r = await fetch('https://captchame.vercel.app/api/pass/verify', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ pass })
});
const { ok, subject, share } = await r.json();
// ok=false: send the visitor to the challenge
// subject='agent': signed agent pass with its share
// subject='human': presence pass, let them in

3. Read your dashboard

Every challenge, verdict, appeal and ledger cap is live at /dashboard.html. Try it now with the demo-site key.

Choose your agent policy

  • Fair share (default): declared agents get 10% of capacity, in order, with a signed pass.
  • Humans only: declarations get a clean refusal; agents cannot buy a way in.
  • Priority lanes (soon): paid, metered agent access for sites that want agent customers.
